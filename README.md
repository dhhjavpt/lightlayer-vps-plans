## 三种线路的区别在网络走向，跟价格无关

同一个洛杉矶机房，Premium、Standard、Global 三个选项的价格完全一样，差别在数据包怎么回国。

**Premium 优化线路**面向中国大陆方向做过调整。洛杉矶 Premium 走三网 CMIN2，台湾 Premium 以 CTGNet 加移动、联通直连为主。代价是带宽小，年付档只有 5Mbps 到 30Mbps。5Mbps 是什么概念：跑一个日 PV 几千的静态站或者 WordPress 完全够，但传一个 1GB 的文件要将近半小时。

**Standard 标准线路**只在洛杉矶提供，走 CMI 直连回国，端口比 Premium 大一档，50Mbps 不限流量或 100Mbps 配 1TB 流量。适合既想国内访问别太慢、又要传点东西的场景。

**Global 国际线路**端口最大，洛杉矶给到 100Mbps 不限流量或 200Mbps 配 1TB，但回国要绕，延迟最高。

延迟数据方面，有第三方测评给出的参考值是：洛杉矶 CMIN2 国内三网 150–180ms，香港、台湾节点 30–50ms，国际线路 200–300ms 且晚高峰有丢包。这些数字来自测评者自己的网络环境和时段，你所在的省份、用的运营商不同，结果可能差不少。真要买，先自己测。

2024 年官方公布过一批测试 IP，比如洛杉矶 128.241.251.254（Premium）、128.241.253.254（Standard）、128.241.233.254（Global），香港 46.8.127.254，台湾 46.8.124.242（Premium）。这些地址距今两年，可能已经调整，拿不到就发工单问，或者直接看官网有没有 Looking Glass。用自己常用的那条宽带做 Ping 和路由追踪，重点看晚八点到十一点的表现，比任何测评数字都准。

1. **不支持升级，不支持退款。** 这是最硬的一条。年付档位下单后无法改配置，也没有无理由退款。
2. **“不限流量”有公平使用政策兜底。** 长期跑满端口可能被限速或要求整改，不是买断带宽。
3. **亚洲优化档的端口很小。** 台湾 Premium 5Mbps、香港和新加坡 Premium 10Mbps。跑网站够用，跑大文件传输会很难受。
4. **1GB 内存装不了 Windows。** Windows 系统至少要 2GB 内存起步，年付档全系 1GB，需要 Windows 得看月付的日本或洛杉矶高配。

## 常见问题

**支持支付宝吗？**
支持。支付宝、PayPal、信用卡都能付，另有资料称也接受加密货币。国内用户付款没有障碍。

**年付能升级配置或者降级吗？**
不能。年付特价套餐不支持配置变更，也不支持退款。要能改配置只能选月付。

**香港机房是原生 IP 吗？**
不是。香港、台湾、新加坡都是非原生 IP，洛杉矶是原生 IPv4。需要原生 IP 直接选洛杉矶。

**1GB 内存能装 Windows 吗？**
不能。Windows 需要至少 2GB 内存，年付档全系 1GB，只能装 Linux 发行版。

**买完不满意能退吗？**
不能。年付特价套餐不支持退款，下单前把机房、线路、端口都确认好。

**怎么判断哪个机房对我快？**
拿测试 IP 自己 Ping 和 traceroute，重点测晚高峰。找不到测试 IP 就发工单要，或者看官网有没有提供 Looking Glass。别人的测评数字只能当参考，你的宽带和他们的不一样。

**流量用超了会怎样？**
不限流量档位受公平使用政策约束，长期占满端口可能被要求调整。固定流量档位（1TB）超了通常需要购买流量包或限速，具体规则看服务条款。
